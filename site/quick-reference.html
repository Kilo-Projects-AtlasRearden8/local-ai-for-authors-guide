Quick reference (printable)

Print this page and keep it next to your computer.

Ollama commands

CommandWhat it does
ollama run llama3.2Start chatting with Llama 3.2
ollama run qwen2.5:7bStart chatting with Qwen 2.5 7B
ollama listShow installed models
ollama pull <model>Download a model
ollama rm <model>Remove a model
ollama stop <model>Stop a running model
/byeExit a chat session

Choosing a model (rule of thumb)

Your RAMSizeExamples
8 GB1B–3BLlama 3.2 1B, 3B
16 GB7B–8BQwen 2.5 7B, Llama 3.1 8B
32 GB+14B–70BLlama 3.1 70B

Slower computer? Use a smaller model.

Prompt templates

Outline Chapter [number], "[title]": goal, scenes in order, one hook.
Write a scene: [context]. Characters: [who]. Setting: [where]. Goal: [what happens]. Tone: [mood]. ~500 words. Show, don't tell.
Line-edit this passage: tighten sentences, remove repeats, fix grammar. Keep my voice. List changes.
Check names, details, timeline, setting for consistency. Flag issues.
Find "telling" phrases. Suggest rewrites that show emotion through action.

Privacy checklist

  • Model runs locally via Ollama
  • Book folder saved on your computer
  • Offline while writing (optional)
  • Weekly backup to USB or second computer
  • Dated drafts before big edits
  • No manuscript text pasted into websites

Remember: you're the editor. The model suggests; you decide. Keep what works, discard the rest. Start small — one chapter, one prompt, one day at a time.
