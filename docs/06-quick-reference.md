# 6. Quick reference (printable)

Print this page and keep it next to your computer.

## Ollama commands

| Command | What it does |
|---------|--------------|
| `ollama run llama3.2` | Start chatting with Llama 3.2 |
| `ollama run qwen2.5:7b` | Start chatting with Qwen 2.5 7B |
| `ollama list` | Show installed models |
| `ollama pull <model>` | Download a model |
| `ollama rm <model>` | Remove a model |
| `ollama stop <model>` | Stop a running model |
| `/bye` | Exit a chat session |

## Choosing a model (rule of thumb)

| Your RAM | Comfortable size | Examples |
|----------|------------------|----------|
| 8 GB | 1B–3B | Llama 3.2 1B, 3B |
| 16 GB | 7B–8B | Qwen 2.5 7B, Llama 3.1 8B |
| 32 GB+ | 14B–70B | Llama 3.1 70B |

Slower computer? Use a smaller model.

## Prompt templates

**Chapter outline:**
```
Outline Chapter [number], "[title]": goal, scenes in order, one hook.
```

**Scene draft:**
```
Write a scene: [context]. Characters: [who]. Setting: [where]. Goal: [what happens]. Tone: [mood]. ~500 words. Show, don't tell.
```

**Line edit:**
```
Line-edit this passage: tighten sentences, remove repeats, fix grammar. Keep my voice. List changes.
[paste text]
```

**Consistency:**
```
Check names, details, timeline, and setting for consistency. Flag issues.
[paste text]
```

**Show, don't tell:**
```
Find "telling" phrases and suggest rewrites that show emotion through action.
[paste text]
```

## Privacy checklist

- [ ] Model runs locally via Ollama
- [ ] Book folder saved on your computer
- [ ] Offline while writing (optional)
- [ ] Weekly backup to USB or second computer
- [ ] Dated drafts before big edits
- [ ] No manuscript text pasted into websites

## Remember

- You're the editor. The model suggests; you decide.
- Keep what works, discard the rest.
- Start small. One chapter, one prompt, one day at a time.
